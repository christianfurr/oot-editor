# OoT Editor

A local companion for the MacNativeGames Ocarina of Time Switch 2 build, update 131072.

- Change the player profile's resolution, upscaler, frame cap, or interpolation for the next launch.
- Back up player save data while the game is closed.
- Quick Start opens the native game with a separate test profile and the runtime's built-in opening skip. It leaves the player profile and active player mods alone.

Build on Apple silicon with `bash build.sh`. The signed app appears in `build/`.
